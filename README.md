# lapoteka.info

Сайт Лапотеки — онлайн-курси для власників собак. Публікується через GitHub Pages на домені lapoteka.info.

- `index.html` — головна сторінка Лапотеки зі списком курсів
- `puppy/index.html` — лендінг курсу «Цуценя без сліз» (перший екран 1, проблеми)
- `puppy/v2.html` — той самий лендінг, перший екран 2 (стан мами), для тесту реклами
- `puppy/oferta.html`, `puppy/privacy.html` — оферта й політика курсу
